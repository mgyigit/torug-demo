# Torug Haber Doğrulama (demo, media version)

The public desk of Torug Haber Doğrulama, a multi-agent misinformation analysis system — the version that
also reads videos and audio recordings. Open it at **https://mgyigit.github.io/torug-demo/**.

- **Arşiv** shows 28 example analyses: 24 text and image claims, plus 4 video and audio examples. They open
  without any server.
- Analyses never use fact-checking organisations as evidence: every verdict is the system's own, reached from
  primary sources.
- **Live analyses** run on the shared analysis server (a Hugging Face Space) with your own API key, entered
  under *Kurulum / Setup*. Keys stay in your browser and go only to that server.
- The previous version stays online as a reference: https://mgyigit.github.io/aletheia-demo/

This repository holds only the built web page; the analysis code is not published.
